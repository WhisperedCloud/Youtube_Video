# Privacy Policy — Ambience Uploader

_Last updated: 14 November 2026_

Ambience Uploader is a private automation tool used only by its owner to upload videos to the owner's own YouTube channel.

- **Data accessed:** The app requests only the `youtube.upload` permission, which it uses solely to upload videos to the owner's channel.
- **Data stored:** No personal data is collected, sold, or shared. OAuth credentials are stored only as encrypted secrets in the owner's GitHub repository and local machine.
- **Third parties:** Video metadata is generated with Google Gemini; stock footage comes from Pixabay. No user data is sent to either.
- **Revoking access:** Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: via the GitHub repository at https://github.com/WhisperedCloud/Youtube_Video
